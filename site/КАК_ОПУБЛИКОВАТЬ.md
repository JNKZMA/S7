# Как опубликовать сайт «Берёзка» (3 минуты)

Папка `site\` — готовый к заливке сайт. Внутри: приложение (`index.html`),
иконки, офлайн-кэш (`sw.js`), `raspisanie.pdf`. Никакой сборки не нужно —
просто залить папку целиком.

## Вариант A — Netlify (быстрее всего)

1. Открыть **https://app.netlify.com/drop**
2. Зарегистрироваться / войти (проще всего через Google-аккаунт).
3. Перетащить мышкой **папку `site`** в окно браузера.
4. Сайт сразу доступен по адресу вида `https://какое-то-имя.netlify.app`.
   В «Site settings → Change site name» задать понятное имя, например
   `berezka-bus` → адрес станет **https://berezka-bus.netlify.app**.
5. Ссылку отправить соседям. На iPhone: открыть в Safari → «Поделиться» →
   «На экран Домой» — появится иконка с автобусом, работает офлайн.

## Вариант B — GitHub Pages

1. Зарегистрироваться на **https://github.com** (если нет аккаунта).
2. «+» → New repository → имя, например `berezka-bus` → Public → Create.
3. «uploading an existing file» → перетащить **содержимое папки `site`**
   (все 8 файлов) → Commit changes.
4. Settings → Pages → Source: «Deploy from a branch» → branch `main`, папка
   `/ (root)` → Save.
5. Через 1–2 минуты сайт на **https://ЛОГИН.github.io/berezka-bus/**.

## Свой домен (по желанию, платно)

Бесплатного адреса (netlify.app / github.io) соседям достаточно. Если хочется
свой, например `berezka.by`:

- Зарегистрировать домен у белорусского регистратора — **hoster.by** или
  **open.by** (.by ≈ 30–60 BYN/год, оплата белорусской картой).
- В Netlify: «Domain settings → Add a domain» → ввести имя → следовать
  инструкции (либо прописать NS-серверы Netlify у регистратора, либо записи
  A/CNAME). HTTPS-сертификат Netlify выдаёт сам, бесплатно.

## После изменения расписания (важно!)

1. Поправить данные в `site\index.html`.
2. В `site\sw.js` поднять версию кэша: `berezka-v1` → `berezka-v2`
   (иначе у соседей на телефонах останется старое расписание).
3. Перезалить папку `site` тем же способом.
